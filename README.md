DueBuddy provides AI-powered invoice OCR and data extraction for Russian businesses, converting PDFs, photos, XML and QR invoices into structured data ready for 1C, DATEV, Excel and other accounting systems. The service offers tiered plans with free trial, supports multiple languages, and includes features like payment reminders and country-specific compliance.

**Areas:** Finance · OCR · Invoicing · API · SaaS

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for DueBuddy: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
